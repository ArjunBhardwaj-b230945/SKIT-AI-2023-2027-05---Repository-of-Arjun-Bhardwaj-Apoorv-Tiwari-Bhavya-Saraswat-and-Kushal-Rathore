# ITR Chatbot

An AI-powered chatbot designed to assist users with **Indian Income Tax Return (ITR)** related queries, tax calculations, and relevant tax information.

## 🚀 Features

- AI-powered tax assistance
- ITR and tax-related query handling
- Tax computation support
- Structured tax schemas and data models
- Interactive conversational interface

## 🛠️ Tech Stack

- Python
- AI / LLM
- LangChain
- RAG
- Vector Database
- FastAPI
